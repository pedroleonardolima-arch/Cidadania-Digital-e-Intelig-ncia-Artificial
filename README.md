# Cidadania-Digital-e-Intelig-ncia-Artificial# Portal de Consciência Digital 2026 🌐🔒

Este portal foi desenvolvido como projeto prático de Recuperação para a disciplina de Educação Digital e IA (Ensino Médio). O objetivo principal é conscientizar a comunidade escolar sobre os impactos das mídias geradas por IA (Deepfakes) e combater a desinformação automatizada na sociedade.

## ✨ Funcionalidades do Projeto
- **Quiz Educativo:** Um validador interativo em JavaScript que ensina o usuário a detectar anomalias visuais em deepfakes.
- **Modo Escuro (Acessibilidade):** Interface adaptável para melhor legibilidade e conforto visual.
- **Design Responsivo:** Layout fluido que se adapta perfeitamente a dispositivos móveis e desktops utilizando CSS Flexbox e Media Queries.

## 🛠️ Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Variáveis nativas e Flexbox)
- JavaScript Assíncrono/Manipulação de DOM

## 🤖 Uso Ético de Inteligência Artificial
Para o desenvolvimento da identidade visual e refatoração da lógica do formulário, foi utilizada a IA auxiliar com os seguintes comandos (prompts):
1. *"Gere uma paleta de cores minimalista e moderna baseada em segurança digital e tecnologia que passe confiança."*
2. *"Como estruturar uma função em JS que capture dados de inputs do tipo radio sem dar crash no navegador se o usuário não selecionar nada?"*
